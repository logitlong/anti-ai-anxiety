- 数据：`events.json` 时间线 · `feed.json` 今天要不要慌 · `deaths.json` / `graveyard.json` 焦虑墓地 · `voices.json` 大佬言论 · `skills.json` 开源与 Skill
- 每日更新规则：[UPDATE_GUIDE.md](UPDATE_GUIDE.md)
